## 1. 系统解决的具体问题、核心功能与目标用户

### 1.1 解决的具体问题

| 问题 | 系统解决方案 |
|------|-------------|
| **信息过载** | 全国300+所高校研究生招生信息分散，系统整合为统一查询入口 |
| **信息不对称** | 提供历年分数线、报录比、学科评估等关键数据 |
| **个性化需求** | 用户画像系统收集考生背景，智能推荐适合的院校 |
| **决策困难** | 性价比算法评估院校，科学化择校建议 |

### 1.2 核心功能

```
┌─────────────────────────────────────────────────────┐
│                    核心功能                          │
├─────────────────────────────────────────────────────┤
│  🎯 智能院校推荐    根据用户画像推荐合适院校         │
│  📊 分数线查询      国家线/校线/自划线查询           │
│  🏆 学科评估查询    第四轮学科评估A类院校            │
│  📖 考研政策解读    学硕专硕、408自命题等           │
│  💡 备考咨询        复习计划、资料推荐               │
│  🔄 多轮对话        支持追问、指代消解               │
│  🌐 联网查询        获取最新招生信息                 │
└─────────────────────────────────────────────────────┘
```

### 1.3 目标用户

- **主要用户**：计算机类考研学生（计算机科学与技术、软件工程、人工智能等）
- **用户画像**：
  - 大三/大四在读本科生
  - 一战或二战考生
  - 在职考研人群

## 3. 使用的NLP典型任务

本系统使用了 **5项** NLP典型任务，远超课程要求的3项：

| 序号 | NLP任务 | 具体实现 | 代码位置 |
|------|--------|---------|---------|
| 1 | **分词** | jieba分词，添加考研领域词典 | `lp_tasks.py` - `WordSegmenter` |
| 2 | **意图识别** | 基于关键词匹配的意图分类 | `lp_tasks.py` - `IntentRecognizer` |
| 3 | **关键词抽取** | 正则+词典的关键词提取 | `lp_tasks.py` - `KeywordExtractor` |
| 4 | **命名实体识别** | 学校名、专业名、分数实体识别 | `lp_tasks.py` - `EntityRecognizer` |
| 5 | **文本分类** | 多级分类（问题类型+专业方向） | `lp_tasks.py` - `TextClassifier` |

### 3.1 分词任务

```python
# 位置: lp_tasks.py - WordSegmenter
from lp_tasks import WordSegmenter

segmenter = WordSegmenter()
tokens = segmenter.segment("推荐一个性价比高的985院校")
# 输出: ['推荐', '一个', '性价比', '高', '的', '985', '院校']
```

### 3.2 意图识别任务

```python
# 位置: lp_tasks.py - IntentRecognizer
from lp_tasks import IntentRecognizer, IntentType

recognizer = IntentRecognizer()
intent, confidence = recognizer.recognize("推荐计算机985院校")
# intent: IntentType.SCHOOL_RECOMMEND, confidence: 0.85
```

### 3.3 关键词抽取任务

```python
# 位置: lp_tasks.py - KeywordExtractor
from lp_tasks import KeywordExtractor

extractor = KeywordExtractor()
keywords = extractor.extract("我预估350分，想去北京")
# keywords: {'score': ['350'], 'region': ['华北', '北京'], ...}
```

### 3.4 命名实体识别任务

```python
# 位置: lp_tasks.py - EntityRecognizer
from lp_tasks import EntityRecognizer

recognizer = EntityRecognizer()
entities = recognizer.extract_entity_dict("东北大学考什么科目？")
# entities: {'school': '东北大学', 'major': None, 'score': None, ...}
```

### 3.5 文本分类任务

```python
# 位置: lp_tasks.py - TextClassifier
from lp_tasks import TextClassifier

classifier = TextClassifier()
result = classifier.classify("计算机408和自命题哪个难？")
# result: {'question_type': '咨询类', 'major_category': '计算机类'}
```

## 4. Agent如何进行任务规划与调度

### 4.1 Agent架构

```python
# 位置: agent.py - GradSchoolAgent
class GradSchoolAgent:
    """
    Agent核心组件:
    1. NLP处理器 - 理解用户意图
    2. 上下文管理器 - 管理对话历史
    3. Skill注册表 - 管理可调用能力
    4. 任务规划器 - 生成执行计划
    5. Skill执行器 - 执行具体任务
    """
```

### 4.2 任务规划流程

```
用户输入: "推荐一个性价比高的985院校，我预估350分"
    │
    ▼
┌─────────────────────────────────────────────┐
│  NLP处理结果                                 │
│  • 意图: school_recommend                   │
│  • 关键词: ['推荐', '性价比', '985', '350']  │
│  • 实体: {level: '985', score: 350}        │
└─────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────┐
│  任务规划 (TaskPlanner)                       │
│  根据意图规则生成任务:                         │
│  1. Task(skill='smart_recommend', priority=3)│
│  2. Task(skill='school_query', priority=1)  │
└─────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────┐
│  Skill调度 (SkillExecutor)                   │
│  按优先级顺序执行:                             │
│  1. 执行smart_recommend → 获取推荐结果       │
│  2. 执行school_query → 获取院校详情          │
└─────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────┐
│  结果整合 (Agent._integrate_results)          │
│  合并多个Skill结果，生成最终回答              │
└─────────────────────────────────────────────┘
```

### 4.3 上下文管理与指代消解

```python
# 位置: agent.py - ContextManager
class ContextManager:
    """上下文管理实现"""
    
    def resolve_reference(self, text: str) -> str:
        """
        指代消解示例:
        用户: "东北大学的分数线是多少？"
        用户追问: "他们的招生人数呢？"
        系统识别: "他们" → "东北大学"
        """
        reference_map = {
            '他们': self.mentioned_entities.get('school', '该校'),
            '它': self.mentioned_entities.get('school', '该校'),
            '这个学校': self.mentioned_entities.get('school', '该校'),
        }
```

### 5.2 Skill基类定义

```python
# 位置: skills.py - BaseSkill
from abc import ABC, abstractmethod

class BaseSkill(ABC):
    """Skill基类 - 所有Skill必须实现以下接口"""
    
    @property
    @abstractmethod
    def name(self) -> str:
        """Skill名称"""
        pass
    
    @property
    @abstractmethod
    def description(self) -> str:
        """Skill描述"""
        pass
    
    @property
    def keywords(self) -> List[str]:
        """触发关键词"""
        return []
    
    @abstractmethod
    def execute(self, params: Dict[str, Any]) -> Dict[str, Any]:
        """执行Skill"""
        pass
    
    def validate(self, params: Dict[str, Any]) -> bool:
        """验证参数"""
        return True
```

### 5.3 Skill注册与调用

```python
# 位置: agent.py - SkillRegistry
class SkillRegistry:
    """Skill注册表"""
    
    def register(self, name: str, skill_instance: BaseSkill):
        """注册Skill"""
        self.skills[name] = skill_instance
    
    def get(self, name: str) -> Optional[BaseSkill]:
        """获取Skill"""
        return self.skills.get(name)
    
    def get_by_intent(self, intent: str) -> List[str]:
        """根据意图获取适合的Skill"""
```

## 7. 系统相比普通大模型Chatbot的区别与价值

### 7.1 核心差异对比

| 特性 | 普通ChatGPT | 本系统 |
|-----|------------|--------|
| **数据来源** | 通用知识，可能过时 | 专业实时数据，知识库持续更新 |
| **个性化** | 无用户画像，千人一面 | 根据用户背景定制推荐 |
| **专业性** | 泛泛而谈，可能"幻觉" | 基于知识库检索，准确可靠 |
| **意图理解** | 通用对话 | 考研领域专项优化 |
| **功能集成** | 仅对话 | 对话+查询+推荐+分析+咨询 |
| **业务场景** | 通用场景 | 垂直领域深度服务 |
| **推荐算法** | 无 | 性价比算法智能推荐 |
| **上下文管理** | 简单 | 支持指代消解、多轮对话 |

### 7.2 系统独特价值

#### 价值1：垂直领域深度优化
- 针对考研场景训练/优化的意图识别
- 理解考研专业术语和政策
- 提供精准的院校推荐算法

#### 价值2：用户画像驱动
- 自动收集用户信息（分数、背景、偏好）
- 基于画像进行个性化推荐
- 记住用户历史对话

#### 价值3：专业数据支撑
- 1216条专业问答知识
- 50+所高校详细信息
- 历年分数线数据

#### 价值4：可量化评估
- 推荐理由有数据支撑
- 分数线、报录比等信息透明
- 给出上岸概率参考
