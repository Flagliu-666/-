# 考研知识库数据

本目录包含考研择校问答系统的所有数据文件。

## 文件说明

### 1. grad_consult_qa.json
考研咨询问答知识库，包含各类考研问题的详细解答。

### 2. schools_data.csv
院校数据库，包含全国各高校的考研招生信息。

### 3. admission_rules.json (待扩充)
考研政策规则知识库。

### 4. subject_requirements.json (待扩充)
各专业考试科目要求。

## 数据来源

### 官方数据源
- **中国研究生招生信息网（研招网）**: https://yz.chsi.com.cn
  - 招生简章、专业目录、分数线
- **教育部官网**: http://www.moe.gov.cn
  - 学科评估、政策文件
- **全国学科评估结果**: http://www.cdgdc.edu.cn

### 非官方数据源
- **考研帮**: https://bbs.kaoyan.com
- **小木虫论坛**: http://muchong.com
- **知乎考研话题**: https://www.zhihu.com/topic/kaoyan

### 院校研究生院官网
各高校研究生院官方网站，权威发布招生信息。

## 数据更新频率
- 分数线数据：每年3-4月更新
- 招生简章：每年9月更新
- 学科评估：每4年更新一次
